# 건설현장 스마트 안전관리 - 공유형 웹앱

## 목표
여러 사람이 같은 URL로 접속하고, 현장별로 데이터를 분리해서 관리하는 구조입니다.

### 포함
- 현장별 관리
- 사용자/현장 권한
- 관리자 페이지
- 현장 기본정보 변경
- 위험성평가 기준(빈도/강도/등급) 웹에서 변경
- 표준 위험성평가 템플릿
- 위험성평가
- TBM
- 조치사항/조치기한
- PostgreSQL 공유 DB
- Render 배포용 render.yaml

## 기본 관리자
이메일: admin@site.local
비밀번호: admin1234

## 배포
Render에서 이 프로젝트를 GitHub 저장소로 올린 뒤 Blueprint로 배포하면 Web Service + PostgreSQL을 함께 만들 수 있습니다.
배포 후 관리자 비밀번호는 반드시 변경하세요.

## 주의
이 버전은 MVP입니다. 실제 운영 전에는 비밀번호 변경/재설정, 감사로그, 파일/사진 저장소, 백업정책, 개인정보/보안 점검 등을 추가하는 것을 권장합니다.
