1. 이 프로젝트 폴더를 GitHub 저장소에 올립니다.
2. Render에 가입합니다.
3. Render에서 New -> Blueprint를 선택합니다.
4. GitHub 저장소를 선택합니다.
5. render.yaml이 Web Service와 PostgreSQL을 생성하도록 확인합니다.
6. 배포가 끝나면 생성된 onrender.com 주소를 팀원들에게 공유합니다.
7. 최초 관리자:
   admin@site.local
   admin1234
8. 첫 로그인 후 관리자 메뉴에서 현장과 사용자를 추가합니다.
9. 관리자 메뉴 -> 위험성평가 설정에서 현장별 기준을 변경할 수 있습니다.

주의: 실제 운영 전에는 관리자 비밀번호 변경, 백업, 보안 설정, 사진 저장소, 감사로그 등을 추가하는 것을 권장합니다.
